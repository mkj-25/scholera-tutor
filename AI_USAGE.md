# AI Usage

AI coding tools were used throughout the development of Scholera Tutor as productivity, debugging, and implementation assistants. They were used to accelerate problem-solving and explore implementation approaches, while the final product decisions, integration, refinement, and understanding of the code remained my responsibility.

## Tools Used

### ChatGPT
Used for:

- Debugging React and JavaScript issues
- Discussing component structure, state flow, and implementation approaches
- Troubleshooting errors
- Refining UI interactions and responsive behavior
- Reviewing code

### Claude
Used as an additional reasoning and code-review assistant for:

- Exploring alternative approaches to implementation problems.
- Reviewing complex logic and component interactions.
- Comparing possible solutions before deciding which approach is the best.

### Antigravity
Used as an AI coding assistant for targeted development tasks, including:

- Component-level implementation and refinements.
- UI improvements and styling iterations.
- Debugging specific interaction issues.
- Assisting with code cleanup and removal of unnecessary code or comments.

## How AI Was Used

AI was used selectively rather than as a replacement for the development process. When I encountered a difficult implementation problem, debugging issue, or something unfamiliar, I used AI to explore possible solutions and understand the problem more quickly.

Examples of areas where AI assistance was useful include:

- React component interactions and state management.
- Chat streaming, cancellation, and error handling.
- Navigation between the chat, course, and learning views.
- Citation and lecture-slide interactions.
- Scroll behavior and navigation to selected course content.
- Responsive and mobile UI behavior.
- Progress visualization and interactive UI components.
- Glass effects, transitions, and other visual refinements.

The suggestions generated by AI were not always used directly. Depending on the situation, I modified the implementation to fit the existing architecture, simplified it, or discarded it entirely.

## My Role in the Project

The overall direction of the product and the decisions around what to build were driven by me.

I made decisions about:

- Which features were worth keeping and which introduced unnecessary clutter.
- How the different parts of the interface should work together.
- The structure and organization of the user experience.
- Which UI iterations improved the learning experience and which should be removed.
- How to keep the project aligned with the assignment's emphasis on depth, craft, originality, and restraint.

A significant part of the development involved iterating on the interface, testing interactions, connecting components correctly, identifying issues, and refining the final experience.

## Where AI Helped Most

AI was particularly helpful in reducing the time required to debug implementation issues and explore unfamiliar or complex parts of the application.

Using different AI tools also made it possible to compare approaches instead of relying on a single generated solution. This was useful when evaluating alternative implementations and deciding which one best fit the existing project.

AI was most valuable as a way to accelerate iteration and problem-solving rather than as a substitute for understanding how the application works.

## Where AI Was Not Enough

AI-generated suggestions were not always directly usable.

Some suggestions introduced unnecessary complexity, added functionality outside the scope of the assignment, or worked independently but did not fit properly into the existing component structure and state flow.

In these cases, the suggested code required modification, simplification, or was discarded.

Keeping the product focused was particularly important for this assignment. Avoiding unnecessary features, reducing UI clutter, and deciding when not to add something required deliberate manual judgement throughout the development process.

## My Approach

I used AI similarly to other development resources such as documentation, technical examples, and developer collaboration: as a tool to solve difficult problems, understand implementation details, and accelerate development.

I retained responsibility for understanding the final implementation and making the product and technical decisions behind it. Before finalizing the project, I reviewed the codebase, removed unnecessary code and comments, and ensured that the remaining implementation was relevant to the final product.

I am able to explain the main components, state flow, interactions, and design decisions in the repository, and I am comfortable making modifications and discussing the trade-offs behind the implementation during a review.
